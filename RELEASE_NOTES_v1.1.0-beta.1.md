PersonalInbox v1.1.0 Beta 1 adds:

- A personal inbox for Discord messages with categories, private notes, search, Done/Undo, and Jump to Message.
- A top-right channel-header launcher and unfinished-item badge.
- Local reminders, custom date and time, snooze, Today and Upcoming views, and overdue reminder recovery.
- A Windows installer that builds and installs the custom Vencord userplugin using the official Vencord repository and installer CLI.

Inbox entries, notes, and reminders stay in Vencord's local IndexedDB-backed storage. No external reminder service is used.

Beta warning: PersonalInbox is currently a custom Vencord userplugin and this installer builds/injects a custom Vencord installation. Please report installation or compatibility issues.
