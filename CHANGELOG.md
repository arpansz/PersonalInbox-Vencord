# Changelog

## 1.1.0 Beta 1

- Added a local PersonalInbox inbox for saved Discord messages.
- Added Important, Reply Later, Read Later, and Other categories, private notes, search, Done/Undo, and Jump to Message.
- Added local reminders, snooze, Today and Upcoming views, and overdue reminder recovery.
- Added a Windows installer that prepares a pinned Vencord source build and invokes Vencord's official installer CLI.

All inbox and reminder data remains in Vencord's local IndexedDB-backed storage.
